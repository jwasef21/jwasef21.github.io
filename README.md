# Digital Business Card & Offline PWA (GitHub Pages Kit)

## Quick Deploy (3 Steps)
1. Create a public repository on GitHub named `<your-username>.github.io`.
2. Upload `index.html`, `manifest.json`, `sw.js`, and `icon.svg` to the root of the repository.
3. In your repository go to **Settings -> Pages**, choose the `main` branch (`/ (root)`), and click **Save**.

## Updating Your Details
- Open `index.html` in any editor and update the `DEFAULT_PROFILE` object near the bottom, OR use the **Customize** button in the browser and click **Download Customized index.html** to replace `index.html`.
- Use the **QR** button inside the app to download a print-ready **SVG** or **PNG** QR code (either Website URL mode or Offline vCard mode).

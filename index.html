Host on GitHub Pages (Offline PWA)

  1. Create a public GitHub repository named username.github.io.
  2. Upload index.html, manifest.json, sw.js, and icon.svg from the companion ZIP kit.
  3. Open Settings → Pages, set source to main branch, and save. Your dynamic card goes live over HTTPS with offline caching enabled automatically.
  4. Open the QR button on this page to export your print-ready SVG/PNG QR code for your physical business card.
